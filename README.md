# MENergy Hunters

Mini game sinh tồn 80 giây, dự thi MEN GEN GAME (MENergy – FSOFT MEN'S DAY 2026).

- Chơi: https://thanhduoc2510.github.io/menergy-hunters/
- Bảng xếp hạng chiếu sân khấu: https://thanhduoc2510.github.io/menergy-hunters/board.html

## Các file
- `index.html`: game (chạy độc lập, không cần cài đặt).
- `board.html`: trang chiếu mã QR và top 10 cập nhật trực tiếp.
- `config.js`: điền URL Firebase Realtime Database để bật bảng xếp hạng trực tiếp. Để trống thì điểm chỉ lưu trên từng máy.
- `firebase-rules.json`: luật bảo mật dán vào Firebase.
- `HUONG-DAN-FIREBASE.md`: các bước cài đặt.

Công cụ AI: Claude (Anthropic) viết code, vẽ bối cảnh, tạo nhạc và âm thanh bằng code.
Sprite nhân vật: Tiny RPG Character Asset Pack 01 và 02 của Zerie (đã mua bản quyền), chỉ dùng trong game này.
Mã QR: thư viện qrcode-generator (giấy phép MIT). Font: Bungee và Be Vietnam Pro (giấy phép SIL OFL 1.1), nhúng sẵn trong file.
