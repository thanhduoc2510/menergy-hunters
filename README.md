# MENergy Hunters

Mini game sinh tồn 80 giây, dự thi MEN GEN GAME (MENergy – FSOFT MEN'S DAY 2026).

Chơi ngay: https://thanhduoc2510.github.io/menergy-hunters/

- Kéo ngón tay (hoặc WASD) để chạy, nhân vật tự tấn công.
- Nhặt MENergy để lên cấp, chiêu mộ đồng nghiệp hoặc tăng phẩm chất.
- Bấm Tuyệt chiêu khi đầy năng lượng. Trùm cuối "Ngày Release" xuất hiện ở giây 50.

Công cụ AI: Claude (Anthropic) viết code, vẽ bối cảnh, tạo nhạc và âm thanh bằng code.
Sprite nhân vật: Tiny RPG Character Asset Pack 01 và 02 của Zerie (đã mua bản quyền), chỉ dùng trong game này.
